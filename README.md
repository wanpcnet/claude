# Véu de Brasas

Jogo 2D top-down de sobrevivência arcana com hordas (PixiJS 8 + WebGL + TypeScript + Vite),
com arte, mapas e áudio originais.

O projeto está em [`veu-de-brasas/`](veu-de-brasas/) — veja o [README do jogo](veu-de-brasas/README.md).

```bash
cd veu-de-brasas
npm install
npm run dev
```
